## 3. API 语义

### `create(options)`

- 在 `storagePath` 创建完整目录骨架 + 空 `catalog.json`
- 若已存在有效库（`meta/catalog.json`）且未 `force: true` → 抛 `DB_EXISTS`
- `force: true` → 删除原目录后重建（危险操作，CLI 需显式 `--force`）
- 返回：`{ storagePath, created: true, version }`
- **不**保持进程内打开状态 / 不长期持文件锁

### `init(options)`

- 若库不存在 → 等价于 create（`created: true`）
- 若已存在 → 确保目录齐全并加载 catalog（`created: false`）
- 返回：`{ storagePath, created, initialized: true, version }`
- 幂等，可重复执行

### 与 `open()` 关系

- `open()`：打开已有/可自动建目录的库并持锁，用于读写
- 推荐流程：`create` 或 `init` → 业务里再 `open`

## 4. CLI 命令一览

```text
jsonsqlite --version | -V | version
jsonsqlite create [path] [--force]
jsonsqlite init [path]
jsonsqlite doctor [--path ./data]
jsonsqlite query '<json>' [--path ./data]
jsonsqlite backup [--path ./data]
jsonsqlite collections [--path ./data]
jsonsqlite help
```

默认 path：参数 > `JSONSQLITE_PATH` > `./data`
