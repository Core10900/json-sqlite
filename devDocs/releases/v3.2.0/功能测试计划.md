# JSONSQLite v3.2.0 功能测试计划

> 前缀：`FT-V32-*`  
> **非 LTS**。不是设计完工放行。不要求复制。

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V32-REG-01 | 默认配置 | FT-V31 回归绿；Redis 与 autoFix 都未启用 |
| FT-V32-VER-01 | version | `3.2.0`，`lts: false` |

## 1. 恢复与质量

| ID | 场景 | 期望 |
|----|------|------|
| FT-V32-PITR-01 | 恢复到时间戳 T | T 之后的变更不在；T 及之前的已提交变更在 |
| FT-V32-PITR-02 | checksum 不符 | 目标库字节不变，稳定错误 |
| FT-V32-TT-01 | 无确认回滚 | 数据不变 |
| FT-V32-TT-02 | `--yes` 回滚 | 数据回到该时间，审计有该操作 |
| FT-V32-TT-03 | 超过保留窗 | 更早的查询有文档化的结果，不抛未说明的异常 |
| FT-V32-DQ-01 | `quality` | 输出五项分数且不写库 |
| FT-V32-DQ-03 | 一项分数偏低 | 报告含对应建议；库中文档不变 |
| FT-V32-DQ-02 | open | 不调用 `autoFix` |
| FT-V32-TUNE-01 | dry-run | 不改缓存大小和压缩配置 |
| FT-V32-TUNE-02 | 校验失败 | 配置回到应用前 |

## 2. 界面、插件、缓存

| ID | 场景 | 期望 |
|----|------|------|
| FT-V32-ADM-01 | 六个 Admin 路径 | 都返回页面或 JSON，而不是 404 |
| FT-V32-ADM-02 | 查询台 | 响应里有五段耗时 |
| FT-V32-WS-01 | `/stream` | 写入后收到对应变更 |
| FT-V32-WS-02 | `/stream` 指标 | 收到与 SSE 相同结构的指标事件 |
| FT-V32-SSE-01 | 原 SSE 路径 | 仍能收到事件 |
| FT-V32-MET-01 | `getMetrics()` | 含窗口 QPS、p50/p95/p99、WAL 字节、表文档数；单写者锁等待为 0 |
| FT-V32-MET-02 | `response_time` 阈值低于实测 p99 | 告警触发；未配置时不新增失败 |
| FT-V32-MET-03 | `/health` | 含内存字节和锁数量；`memoryWatermarkBytes: 0` 时不因此 degraded |
| FT-V32-EVT-01 | 监听 `metrics` | 在默认间隔内收到与 `getMetrics()` 同结构的事件 |
| FT-V32-EVT-02 | 无 `error` 监听器时写入失败 | 进程仍在；错误计数增加 |
| FT-V32-TX-01 | `transactionTimeoutMs: 0` | 短事务与 3.1 一样提交 |
| FT-V32-TX-02 | 超时短于事务内的等待 | 事务回滚，稳定错误，库中没有部分写入 |
| FT-V32-PLG-01 | 坏版本的插件 | 不注册；随后查询成功 |
| FT-V32-PLG-02 | 钩子抛错 | 错误被记录；随后查询成功 |
| FT-V32-PLG-03 | `queryLanguage.parse` 返回非 JSON 查询 | 拒绝执行；原查询路径仍可用 |
| FT-V32-L3-01 | 不安装 Redis 客户端 | `open` 成功，L3 为关闭 |
| FT-V32-ADV-01 | 拒绝一条建议 | 下一次不自动建该索引 |
| FT-V32-DLT-01 | 更新一个字段 | delta 不含未修改字段 |
| FT-V32-DLT-02 | 达到快照阈值 | 生成带 checksum 的快照后才删除更旧 delta |
| FT-V32-DLT-03 | 快照 checksum 不符 | 旧 delta 仍在 |
| FT-V32-CHAOS-01 | 注入磁盘满或 EACCES | 写入失败；此前提交的文档可打开 |
| FT-V32-CFG-01 | `config validate` | 接受默认关闭的 `l3`；仍拒绝 `replica` |
| FT-V32-EXP-01 | `exports["./plugin"]` | 能解析类型入口；包内没有 `src/` |

## 3. 性能与文档

| ID | 场景 | 期望 |
|----|------|------|
| FT-V32-PERF-01 | 包络文件 | 含点查、过滤、批量写、范围、全文、并发读写的实测字段 |
| FT-V32-PROP-01 | 属性测试 | CI 日志里有运行记录 |
| FT-V32-DOC-01 | Release | 含非 LTS，不含「设计完工」或 Vision Complete |

## 放行

1. REG、PITR、TT-01、TT-02、ADM、WS、L3 全绿。  
2. 包络文件缺失，或 README 里的数字和包络文件不一致，不得发版。
