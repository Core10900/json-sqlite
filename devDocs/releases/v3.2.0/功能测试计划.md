# JSONSQLite v3.2.0 功能测试计划

| ID | 场景 | 期望 |
|----|------|------|
| FT-V32-REG-01 | 复制关闭的单机路径 | 绿 |
| FT-V32-REG-02 | FT-V30 复制雏形 | 绿 |
| FT-V32-REG-03 | FT-V31 Quorum / 路由 / 冷存储故障 | 绿 |
| FT-V32-REP-01 | 杀主 | 不自动选主 |
| FT-V32-LTS-01 | compatibility | `lts: true`，线 `3.2` |
| FT-V32-CLI-01 | 帮助文本 | 无 `cluster`；与冻结 CLI-API 一致 |
| FT-V32-VER-01 | version | `3.2.0` |

## 放行

1. 上表全绿。  
2. 自 3.1 浸泡结束以来无新功能。  
3. Release 写明本 LTS 不含自动选主。  
4. 不得把 `lts` 主 tag 从 2.2 改到本版，除非另有发版决议；本计划默认只打 `lts-4`。
