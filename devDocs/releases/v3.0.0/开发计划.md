## 1. 背景：何谓「全部功能完成」

相对 `design/`：

- 《技术实现方案》P0–P5 及 §8 运维/插件

`⛔` 边界（完整 SQL 方言、替代 ES/ClickHouse 产品定位、强制 GPT Advisor）**永不**进入验收。

## 2. 目标

1. **集群**：Raft 裁剪选主（或等价共识）+ 自动分片/rebalance + 跨机锁；读写分离在集群语义下正确  
2. **Vector 索引插件**可用实现（非空 stub）：相似度检索 API + 文档说明非「通用向量库」  
3. **WASM** 可选包：浏览器/边缘只读或受限读写（能力矩阵写清）  
4. 矩阵收官：无残留未解释大纲能力  
5. 文档与兼容信息：`lts: '3.0'`；相对 LTS-2 迁移指南；宣布 LTS-1/LTS-2 窗口策略  

```text
LTS-1 1.6 ──┐
LTS-2 2.2 ──┼──► 迁移指引 ──► 3.0 LTS-3（主推荐）
2.3 适配 ───┘
```

### 成功标准

- ≥3 节点：选主、复制、分片迁移、故障切换有自动化或可脚本混沌测  
- FEATURE-MATRIX 无 `📅`  
- FT-V30-* 全绿；发布 `3.0.0` + Release 标题含 **LTS-3 / Vision Complete**  

### 明确仍可不做（保持 ⛔）

完整 SQLite 方言；宣称取代 ES/ClickHouse；强制云端 LLM。

## 5. LTS-3 承诺（文首条文草案）

1. 3.0.x PATCH：仅安全与正确性；集群协议变更若不可避免须可迁移且记 MAJOR 或明确例外  
2. 稳定符号以 3.0 `API.md` / `CLI-API.md` / 集群手册为准  
3. 大功能进 **3.1+**（小增强）或 **4.0**（下一代愿景）  
4. 建议新项目默认 pin `3.0.x`；1.6 / 2.2 按日历进入安全-only 直至 EOL
