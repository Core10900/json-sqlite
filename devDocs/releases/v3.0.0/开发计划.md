# JSONSQLite v3.0.0 开发计划

> 包名：`@webofcat/jsonsqlite`  
> 主题：**异步复制雏形**  
> 前置：**LTS-2（2.2）** 已是单机生产 pin；多写者契约以 **LTS-3（2.5）** 为准。复制建立在已经能恢复的单机之上  
> **LTS：否**。本版也**不是**设计完工版  
> 兼容：**MAJOR**（复制日志格式）。单机默认模式必须仍能打开 2.5 库；不开启复制时行为与 LTS-3 默认单写者一致  
> 路线图：[../ROADMAP.md](../ROADMAP.md) · 矩阵：[../FEATURE-MATRIX.md](../FEATURE-MATRIX.md)

---

## 1. 背景

方案 Phase 5 的验收是异步主从 demo，加上列存相对文档模式的可测加速。列存已放在 2.3。本版只做复制雏形，把选主和自动分片留在 3.4，并且 3.4 首发不能当 LTS。

生产级数据库的高可用如果做不到手动可恢复，就不要做成「看起来会自动选主」。

---

## 2. 目标

1. 复制默认关闭。关闭时回归 LTS-3 的单机测试。  
2. 开启后：一个主、一个或多个从；主的已提交写入最终在从库可见。  
3. 从库滞后可在 metrics 与 `doctor` 中读到。  
4. 主宕机：**不**自动选主。文档与测试断言从库停在已复制的前缀，由运维按手册处理。  
5. 分片路由可以有 hash/range 的实验开关，默认关。实验开关失败不阻塞 3.0 发版；未实现则不要出现在稳定 CLI 里。  
6. 提供 2.5 → 3.0 的单机迁移。开启复制不是迁移的必选项。

### 成功标准

- 两节点最终可见有自动化测试。  
- 杀死主进程后，从库不接受写入冒充新主（除非用户按文档把从库提升，且该步骤是显式命令）。  
- FT-V30-* 全绿。Release 标题含 **非 LTS**，不含 Vision Complete。

### 不做

Raft、自动 rebalance、跨机锁、Quorum 写成功条件、GraphQL、WASM。Quorum 与读写分离在 **3.1**。复制生产 pin 是 **3.2（LTS-4）**。

## 4. 文档交付：同步更新 `packages/core/README.md`

本版开发完成、勾选验收之前，必须在同一次交付里更新 [`packages/core/README.md`](../../../packages/core/README.md)。复制属于 MAJOR 行为，只改版本号、或把「主从」写成已经高可用，都不算完成。

写作要求：

- 与复制 RFC、默认关闭、以及「不自动选主」的测试断言一致。命令与正文不使用 failover 来描述自动切换；提升从库只写成显式步骤。
- 读者要能判断：不开启复制时库是否仍是 LTS-3 的单机、如何打开复制、滞后看哪里、主宕机后自己要做什么。
- 示例使用真实配置、API 与 `replica` 命令，可复制。未进入稳定 CLI 的能力不出现在命令一览里。
- 文首写明 **3.0.0、非 LTS**，并写明本版不是设计完工版。单机生产 pin 仍是既有 LTS 线。

本版 README 必须写清：

1. 兼容：相对 2.5 为 **MAJOR**（复制日志格式）。不开启复制时必须仍能打开 2.5 库，行为与 LTS-3 默认单写者一致。用对照写「关闭」和「开启」两种启动方式。
2. 复制默认关闭。开启后的拓扑是一个主、一个或多个从。主的已提交写入最终在从库可见：写明「最终」不是同步确认，调用方不能把主库提交成功理解成从库已经收到。
3. 初始化与观察：`replica init` 与 `replica status` 的示例。滞后在 metrics、`doctor`、`replica status` 中分别是哪个字段，单位或含义是什么，滞后变大时读者第一步看什么。
4. 主宕机：**不**自动选主。从库停在已复制的前缀，不接受写入冒充新主。提升从库是显式命令，按手册把步骤写进 README（可链到手册，但命令顺序和危险点必须在 README 里）。写明没有这条显式命令时，从库保持只读前缀。
5. 分片：hash/range 若只是默认关闭的实验开关，写明默认关、失败不影响单机使用、不在稳定 CLI 中。若本版未实现，README 不出现「已支持分片」。
6. 迁移 **2.5 → 3.0** 的单机步骤。开启复制不是迁移的必选项，步骤里单独标出「可停在复制关闭」。
7. 路线：Quorum 与读写分离在 **3.1**。复制的生产 pin 是 **3.2（LTS-4）**。本版不做 Raft、自动 rebalance、跨机锁、Quorum 写成功条件、GraphQL、WASM。
8. CLI：有 `replica init` 与 `replica status`，没有 `cluster`。不要在帮助文本或 README 命令表里预告 `cluster`。
