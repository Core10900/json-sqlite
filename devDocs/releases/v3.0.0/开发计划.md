## 1. 目标

2.5 的读路径能用，但和方案 §5 还有差距：JSONPath 只能取字段，超时发生在查询返回之后，优化器不会估算选择率，剖析只有两段耗时，chunk 把匹配行全部攒齐再排序。本版把这些补到可验证，作为 3.1 存储改造的读路径。

1. JSONPath 支持比较和存在判断（例如 `$[?(@.age>18)].name` 这一级的过滤）。执行器是安全表达式树。相同路径的解释树放进 LRU，缓存键是路径文本，不含文档或参数。默认不使用 `new Function`。  
2. `queryTimeout` 能打断正在扫描的查询。调用方可以传 `AbortSignal`。取消之后不返回部分结果冒充成功。  
3. 计划器做常量折叠、参数绑定、投影下推、LIMIT 早停，并按「选择率 × 索引类型权重」选索引。参数先绑定再折叠，用户值不拼进语句文本。没有排序、且不需要全量聚合时，扫到 `offset + limit` 即停。没有统计时退回 2.5 的规则选择，结果与全表过滤一致。  
4. 剖析分成 parse、optimize、indexScan、dataLoad、execute，并给出内存增量。  
5. 分批执行按 chunk 过滤和投影，再排序分页。`queryChunkSize > 0` 的结果与关掉 chunk 的结果一致。  
6. SQL 子集：单个 `GROUP BY` 字段支持 `COUNT` / `SUM` / `AVG` / `MIN` / `MAX`。不支持的语法返回稳定错误，错误文本指出构造名。  
7. 受控编译默认关闭。只有引擎生成的白名单运算符可以编译，用户字符串不能拼进函数体。本版不把编译设为默认。是否改成默认，由 3.2 的百万文档包络决定，本版只提供开关。  
8. Advisor 在现有索引建议和结构改写之外，给出一条替代 JSONPath，并给出预估代价。预估使用本版剖析字段，不调用外部模型。

### 成功标准

- 2.5 的 FT-V25 single 路径绿。  
- 同一查询在有索引、无索引、开 chunk、关 chunk 时文档集合一致。  
- 超时和取消有测试：扫描开始后中止，调用方看到 `QUERY_TIMEOUT` 或取消错误，库仍可下一次查询。  
- FT-V30-* 全绿。Release 标明 **非 LTS**。

### 不做

B+Tree、列编码、hybrid、复制、Redis、GraphQL、集群、WASM。完整 SQLite 方言不在 3.x。

## 3. 文档交付：同步更新 `packages/core/README.md`

本版开发完成、勾选验收之前，必须在同一次交付里更新 [`packages/core/README.md`](../../../packages/core/README.md)。只改版本号、或把 JSONPath 写成完整规范，都不算完成。

写作要求：

- 说明文字用中文。本版改到的 `packages/core/README.md` 与仓库根 `README.md` 都用中文写。命令、配置键、错误码和代码示例保持原文。用英文段落代替中文说明不算完成。
- 与已测的语法范围、错误码、默认开关一致。不支持的 JSONPath 和 SQL 构造写成「会报哪一个错误」。
- 读者要能判断：不传新参数时，2.5 的查询是否仍得到原来的文档。
- 示例使用真实 API 与 `jsonsqlite` 命令，可复制。
- 文首写明 **3.0.0、非 LTS**。生产 pin 仍是 LTS-2；需要多写者仍用 LTS-3。

本版 README 必须写清：

1. 兼容：相对 2.5 为 MINOR，文档页格式不变，默认仍是单写者。用一对查询说明旧过滤的结果不变。
2. JSONPath：列出支持的过滤形式和明确不支持的形式（脚本、递归下降）。给出一条过滤示例和一条被拒绝的示例，写明错误码。写明相同路径会复用解释树。
3. 取消：`queryTimeout` 与 `AbortSignal` 的调用示例。写明中止后没有部分成功结果，下一次查询仍可用。
4. `explain`：选择率、索引权重、分批与否、是否早停，各是哪个字段。没有统计时计划如何退回。参数绑定的示例使用占位符，不把值拼进语句。
5. Advisor 的替代 JSONPath 和预估代价出现在哪一个字段。未执行的查询也可以调用建议。
6. 分批：`queryChunkSize` 的默认值和打开方式。写明结果与关闭时一致，排序发生在分批过滤之后。
7. SQL：单字段 `GROUP BY` 支持的聚合函数列表。写出一条不支持语句和它的稳定错误，避免写成「支持 SQL」。
8. 编译开关的配置名、默认关闭、打开后仍然拒绝把用户字符串拼进函数体。
9. 明确不在本版：B+Tree、新的列存编码、复制、Redis、GraphQL、集群、完整 SQL 方言、`READ_UNCOMMITTED`。

## 5. 风险

| 风险 | 缓解 |
|------|------|
| 优化器改变结果 | 等价测试是发版门禁；无统计时走原规则 |
| `new Function` 注入 | 默认关闭；只编译引擎白名单 |
| 取消后锁未放 | 取消路径与正常返回共用释放 |
