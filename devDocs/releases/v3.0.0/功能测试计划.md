# JSONSQLite v3.0.0 功能测试计划

> 前缀：`FT-V30-*`  
> **非 LTS**。不要求复制、集群或百万文档包络。

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V30-REG-01 | 默认配置打开 2.5 库 | FT-V25 single 路径绿；页格式不变 |
| FT-V30-VER-01 | version | `3.0.0`，`lts: false` |

## 1. 查询

| ID | 场景 | 期望 |
|----|------|------|
| FT-V30-JP-01 | JSONPath 比较过滤 | 与等价 JSON filter 的 `_id` 集合一致 |
| FT-V30-JP-02 | 脚本或 `..` | 稳定错误，不执行 |
| FT-V30-JP-03 | 同一条 JSONPath 连续执行 | 结果一致；第二次不重新解析出另一棵树 |
| FT-V30-CAN-01 | 扫描中超时 | `QUERY_TIMEOUT`，结果不是成功数组 |
| FT-V30-CAN-02 | `AbortSignal` | 同上，之后的查询成功 |
| FT-V30-OPT-01 | 有等值索引 | `explain` 写出索引与选择率 |
| FT-V30-OPT-02 | 常量折叠 | 折叠前后命中文档一致 |
| FT-V30-OPT-03 | 无排序且有 limit | 扫描在达到 offset+limit 后停止，结果与全表过滤后截断一致 |
| FT-V30-BIND-01 | 参数绑定 | 值不出现在解析后的语句文本里；结果与字面量查询一致 |
| FT-V30-ADV-01 | advise | 含替代 JSONPath 与预估代价；不访问网络 |
| FT-V30-CHK-01 | chunk 开与关 | 排序后的文档一致 |
| FT-V30-SQL-01 | `GROUP BY` + `SUM` | 与聚合管道同一数字 |
| FT-V30-SQL-02 | 不支持的 SQL | 错误文本含构造名 |
| FT-V30-PRF-01 | 剖析 | 含 parse、optimize、indexScan、dataLoad、execute 与内存增量 |

## 2. 安全与 CLI

| ID | 场景 | 期望 |
|----|------|------|
| FT-V30-JIT-01 | 默认配置 | 不调用 `new Function` |
| FT-V30-JIT-02 | 打开编译后喂入字符串拼接 | 拒绝，查询不执行该字符串 |
| FT-V30-CLI-01 | `explain --json` | 非 TTY 可解析 |
| FT-V30-CLI-02 | 帮助文本 | 无 `replica`、`cluster` |

## 放行

1. REG、JP、CAN、CHK、SQL 全绿。  
2. 旧查询结果变化且没有写入 Release 的，不得发版。
