# JSONSQLite v3.0.0 功能测试计划

> 前缀：`FT-V30-*`  
> **非 LTS**。不是 Vision Complete 放行。不要求矩阵清零，不要求集群。

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V30-GATE-01 | 复制 RFC | 含「不自动选主」与手动 promote 步骤 |
| FT-V30-REG-01 | 复制关闭 | 单机 FT-V25 的 single 路径绿 |

## 1. 复制

| ID | 场景 | 期望 |
|----|------|------|
| FT-V30-REP-01 | 主写入 | 从库在文档化的延迟内可见 |
| FT-V30-REP-02 | 从库落后 | `replica status` 有滞后字段 |
| FT-V30-REP-03 | 杀死主进程 | 从库不自动接受写入；已复制前缀仍在 |
| FT-V30-REP-04 | 显式 promote（若本版提供） | 只有执行命令之后，原从库才可写 |
| FT-V30-MIG-01 | 2.5 库迁移且不启复制 | 抽样一致；仍是单写者 |

## 2. 文档

| ID | 场景 | 期望 |
|----|------|------|
| FT-V30-CLI-01 | `replica status` | 非 TTY，可 JSON |
| FT-V30-CLI-02 | 稳定帮助 | 无 `cluster` 子命令 |
| FT-V30-VER-01 | version | `3.0.0`，`lts: false` |
| FT-V30-DOC-01 | Release | 文本包含非 LTS，且不包含 Vision Complete |

## 放行

1. REG 与 REP-01–03 全绿。  
2. 出现自动选主行为则不得发版。
