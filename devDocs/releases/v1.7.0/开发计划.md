## 1. 背景与目标

```text
1.6  ★ LTS-1：契约冻结（库 + CLI 面）  ✅ 已封版
1.7  体验补齐 + 1.6 后兼容增强         ← 本文
1.8  性能与存储预备（非 LTS）
2.0–2.1  破坏性一代 + 硬化（非 LTS）
2.2  ★ LTS-2
3.0  ★ LTS-3 / Vision Complete
```

相对设计愿景，1.6 已具备 Advisor / TimeTravel / 简易 Admin / `subscribe`，但仍缺「演示 10 分钟闭环」所需的完整运维 UI、实时推送与自动调优开关。同时聚合管道缺少 `unwind` / `lookup`，索引缺复合类型——这些都可在 **不破坏 1.6 契约** 的前提下交付。

### 1.7 成功标准

1. Admin Web 可完成：看指标 → 看慢查询 → 看索引建议 → 触发备份 → 时间点查询（文档演示脚本 ≤ 10 分钟）  
2. WebSocket（或 SSE，二选一并文档化）可推送 metrics / `dataChanged`  
3. `StreamProcessor` 提供可测的滑动窗口示例 API（能力边界写清）  
4. `AutoTune` / 自动建索引：**默认关闭**；开启后有审计日志与回滚建议  
5. `CompositeIndex` + 基础 `autoSelectIndexType`  
6. 聚合阶段支持 `unwind`、`lookup`  
7. 允许新增少量 CLI（如 `admin` 启动说明或 `advise`）；更新根目录文档增补节  
8. FT-V17-* 全绿；回归含 V16 / V155  

### 1.7 不做

| 项 | 留给 |
|----|------|
| 多写者 / 文件锁语义变更 | 2.0 |
| 列存 / 热冷分层落地 | 1.8 雏形 / 2.0 |
| L3 Redis、集群复制 | 2.0 |
| 默认 `schemaMode: strict` | 2.0（可选） |
| 完整 SQL 方言、子查询窗口函数 | 长期非目标 / 评估后 1.8+ 极小集 |

| V17-ADM-1 | Admin 页面 | 仪表盘、表浏览、查询台、慢查询、索引建议、备份入口 |

| V17-IDX-2 | autoSelectIndexType | 低基数→object；有序数值→tree；长文本→inverted；多字段过滤→composite |
| V17-AGG-1 | unwind / lookup | 进入 `aggregate` 管道；lookup 内存哈希 |
| V17-CLI-1 | CLI-API 适配（1.7） | 见 **§2.1**；细则 [../CLI-EVOLUTION.md](../CLI-EVOLUTION.md) |

| V17-QA-1 | 契约 | 1.6 符号仍在；新增符号与 CLI 命令全部文档化 |
| V17-FIX-1 | 1.6 后兼容优化入口 | 见 §1.1；不回写 `v1.6.0/开发计划.md` |

### 2.1 CLI-API 适配（1.7）

在 **不破坏 1.5.5/1.6 稳定命令语义** 前提下扩展：

| ID | 命令 / 改动 | 说明 |
|----|-------------|------|
| V17-CLI-A | `admin serve` | 启动 Admin（host/port/token flags；非 loopback 强制 token） |
| V17-CLI-B | `advise '<sql\|json>'` | Advisor；`explain` 保留并与输出字段对齐 |
| V17-CLI-C | `index create … --type composite --fields a,b` | 复合索引 |
| V17-CLI-D | `aggregate '<pipeline-json>'` | 含 unwind/lookup |
| V17-CLI-E | `compat` 或 `version --json` | 打印 `getCompatibilityInfo()` |
| V17-CLI-F | `watch`（可选） | 订阅 dataChanged；非 TTY 须 `--once`/`--timeout` |
| V17-CLI-G | 根 `CLI-API.md` | 新增「1.7 增补」速查行 + help 分级 |
