# JSONSQLite v1.7.0 功能测试计划

> 用例前缀：`FT-V17-*`  
> 重点：Admin / 实时推送 / AutoTune / 复合索引 / 聚合 unwind·lookup  
> 回归：V12–V16 + V155 必须绿

---

## 1. Admin / 实时

| ID | 场景 | 期望 |
|----|------|------|
| FT-V17-ADM-01 | 启动 Admin（loopback） | 仪表盘 HTML 200 |
| FT-V17-ADM-02 | 非 loopback 无 token | 拒绝启动（与 1.4+ 一致） |
| FT-V17-ADM-03 | `/metrics` `/health` | JSON 字段稳定 |
| FT-V17-ADM-04 | advise / profile API | 返回建议或分段耗时 |
| FT-V17-ADM-05 | 备份入口 | 可触发 full backup |
| FT-V17-WS-01 | 订阅通道 | 写入后收到 dataChanged（或等价事件） |
| FT-V17-WS-02 | 无鉴权非法源 | 拒绝 |

## 2. Stream / AutoTune

| ID | 场景 | 期望 |
|----|------|------|
| FT-V17-STR-01 | 滑动窗口聚合 | 窗口内计数/求和正确 |
| FT-V17-STR-02 | 边界空窗口 | 稳定空结果，不抛 |
| FT-V17-TUN-01 | 默认 autoTune off | 慢查询不自动建索引 |
| FT-V17-TUN-02 | dry-run | 只产出建议不改库 |
| FT-V17-TUN-03 | autoTune on | 可创建推荐索引；可关闭 |

## 3. 索引 / 聚合

| ID | 场景 | 期望 |
|----|------|------|
| FT-V17-IDX-01 | Composite 等值前缀 | 命中索引路径（metrics/advisor 可观测） |
| FT-V17-IDX-02 | 写后索引一致 | update/delete 后查询正确 |
| FT-V17-IDX-03 | autoSelect | 典型字段选中合理类型 |
| FT-V17-AGG-01 | unwind | 数组展开行数正确 |
| FT-V17-AGG-02 | lookup | 联接字段匹配；无匹配为空数组/空 |

## 4. CLI / 文档 / 兼容

| ID | 场景 | 期望 |
|----|------|------|
| FT-V17-CLI-01 | `admin serve --help` | exit 0；含 host/port |
| FT-V17-CLI-02 | `advise` / `compat` 或 `version --json` | `--json` 合法；非 TTY 不挂起 |
| FT-V17-CLI-03 | `index create --type composite` | 非 TTY 成功路径 |
| FT-V17-CLI-04 | `aggregate`（若交付） | pipeline JSON；错误包络稳定 |
| FT-V17-DOC-01 | API.md 含新符号 | 导出 ⊆ 文档 |
| FT-V17-DOC-02 | CLI-API 1.7 增补 | 新命令入速查表；help ⊆ 文档 |
| FT-V17-REG-01 | 1.6 契约回归 | FT-V16 相关全绿 |
| FT-V17-VER-01 | `getVersion()` | `1.7.0`；`getCompatibilityInfo().lts` 策略按发版说明（1.7 可为非 LTS 或延续说明） |
