# JSONSQLite v3.4.0 功能测试计划

> 前缀：`FT-V34-*`  
> **实验发布测试**。通过与否都不构成 LTS 放行。禁止以「矩阵已无排期项」作为本版发版标题。

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V34-GATE-01 | 集群 RFC | 分区与双主的断言在实现前已写明 |
| FT-V34-REG-01 | 集群开关关闭 | LTS-4 单机与异步复制回归绿 |

## 1. 混沌

| ID | 场景 | 期望 |
|----|------|------|
| FT-V34-CLU-01 | 三节点启动 | 唯一主 |
| FT-V34-CLU-02 | 主上提交后从可读 | 符合 RFC 的可见性 |
| FT-V34-CLU-03 | 杀死主 | 新主；已提交仍在 |
| FT-V34-CLU-04 | 网络分区 | 不同时有两个主接受写 |
| FT-V34-CLU-05 | rebalance | 迁移前后文档可查，或得到明确错误；抽样无静默丢失 |
| FT-V34-CLU-06 | 跨机锁冲突 | 稳定错误码 |

## 2. 可选包与发布约束

| ID | 场景 | 期望 |
|----|------|------|
| FT-V34-WASM-01 | WASM 包若交付 | 文档中的子集可跑；未交付则本条跳过并在 Release 说明 |

| FT-V34-DOC-01 | Release 文本 | 含非 LTS；列出未通过的混沌项；不含 Vision Complete |

## 放行（实验，不是 LTS）

1. GATE 与 REG 必须绿。  
2. CLU 项允许部分失败，但失败必须写进 Release，且对应命令不得标为支持。  
3. 全部 CLU 都绿，仍然**不能**在本版宣布 LTS。最早另开 3.5 计划，在只修缺陷的浸泡之后再讨论 LTS-5。
