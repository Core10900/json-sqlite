## 1. LTS（长期稳定）标注规则

| 代号 | 版本线 | 何时宣布 | 适合谁 | 维护内容 |
|------|--------|----------|--------|----------|
| **LTS-1** | **`1.6.x`** | ✅ 已宣布（1.6.0） | 单写者嵌入式；要契约冻结 | 安全 / 正确性 / 文档勘误；**不扩 CLI** |
| — | `1.7.x`–`1.8.x` | **不是 LTS** | 要 Admin/性能、可跟 1.x 升级 | 随 MINOR 前进；1.8 可短维护至 2.0 迁移窗口结束 |
| — | `2.0.x`–`2.1.x` | **不是 LTS** | 尝鲜多写者/列存 | 破坏性后浸泡期；只修阻断缺陷 |
| **LTS-2** | **`2.2.x`** | 2.2.0 发版时宣布 | 已迁 2.x、要生产 pin | 安全/正确性；行为兼容 2.2 契约 |
| — | `2.3.x` | **不是 LTS** | 要 GraphQL/多库适配 | 功能列车 |
| **LTS-3** | **`3.0.x`** | 3.0.0 发版时宣布 | 要「大纲能力完工」的最终 pin | **Vision Complete**；此后大功能进 3.1+ 或 4.0 |

**并行维护约定**

- LTS-1（1.6）与 LTS-2（2.2）可重叠一段窗口（建议 ≥12 个月或至 LTS-3 发布后 6 个月，以 Release 声明为准）  
- 安全补丁：**现行 LTS 优先**；非 LTS 的最新 minor 尽力  
- 新功能：**永不**塞进已冻结的 LTS PATCH，除非安全必需且兼容

## 4. 设计能力 → 版本（摘要）

详见 [FEATURE-MATRIX.md](./FEATURE-MATRIX.md)。高层映射：

| 阶段 | 能力包 |
|------|--------|
| **1.7** | Admin/WS/Stream/AutoTune/Composite/unwind·lookup；**CLI**：`admin serve` / `advise` / `aggregate` / `compat`… |
| **1.8** | 索引落盘、L2、压缩、热冷 flag、bench、CI；**CLI**：`index rebuild` / doctor·stats 扩展 |
| **2.0** | 多写/列存/插件/复制雏形；**CLI**：`migrate` / `plugin` / `replica`（可破坏文档） |
| **2.1** | RR/SER、死锁、差异备份、告警审计、Quorum；**CLI**：`backup --type` / `tune` / `audit` |
| **2.2 LTS-2** | Geo/L3/读写分离…；**CLI 面冻结**（含 geo index、compat LTS 标记） |
| **2.3** | GraphQL/连接池/多库；**CLI**：`db *` / `serve graphql` |
| **3.0 LTS-3** | 集群收官 + 矩阵清零；**CLI 面再冻结**（`cluster` / `plugin` 全量） |
