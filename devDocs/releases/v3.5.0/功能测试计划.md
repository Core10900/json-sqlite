# JSONSQLite v3.5.0 功能测试计划

> 前缀：`FT-V35-*`  
> **非 LTS**。混沌三项是发版门禁，不是可选项。

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V35-GATE-01 | RFC | 仓库内有选主、分区、rebalance、跨机锁 |
| FT-V35-REG-01 | 集群关闭 | 3.4 单机与复制关闭路径绿 |
| FT-V35-VER-01 | version | `3.5.0`，`lts: false` |

## 1. 混沌

| ID | 场景 | 期望 |
|----|------|------|
| FT-V35-CLU-01 | 三节点启动 | 状态里只有一个主 |
| FT-V35-CLU-02 | 杀死主 | 按 RFC 选出新的唯一主；已提交文档仍在 |
| FT-V35-CLU-03 | 网络分区 | 两个主不会同时写入成功 |
| FT-V35-CLU-04 | rebalance 中查询 | 成功，或稳定错误；文档数不悄悄变少 |
| FT-V35-CLU-05 | 跨机锁冲突 | 稳定错误码，另一方的已提交写入仍在 |
| FT-V35-ADV-01 | 数据倾斜建议 | Advisor 输出建议；不执行 `rebalance` |

## 2. CLI 与 WASM

| ID | 场景 | 期望 |
|----|------|------|
| FT-V35-CLI-01 | 集群关闭时的帮助 | 不把 `cluster` 写成默认可用 |
| FT-V35-CLI-02 | 集群打开 | 已通过的子命令有非 TTY JSON |
| FT-V35-WASM-01 | 可选包 | 元数据含 experimental 与只读；主 bin 不包含该入口；能执行一条只读查询 |
| FT-V35-CFG-01 | `config validate` | 接受默认关闭的 `cluster` 与 `wasm` |
| FT-V35-DOC-01 | Release | 含非 LTS 与三项混沌通过；不含设计完工 |

## 放行

1. GATE、REG、CLU-01 至 CLU-05 全绿。  
2. 任一项混沌失败，不得发布 `3.5.0`。
