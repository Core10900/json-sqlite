# v3.5.0 npm 发布说明

> 包名：`@webofcat/jsonsqlite`。只读 WASM 可以是另一个包  
> 功能与测试：[开发计划.md](./开发计划.md) · [功能测试计划.md](./功能测试计划.md)  
> **禁止把本版标成 LTS。** 禁止在 npm description、GitHub Release 标题里写设计完工或 Vision Complete。

混沌三项没有全部通过时，不发布 3.5.0。不要发一个「实验性已支持」的 3.5.0 来占版本号。

不带版本号的 `npm view @webofcat/jsonsqlite` 读的是 `latest`。`latest` 表示最新发布，不表示生产 pin。本版必须移动 `latest`，同时禁止移动 `lts`。把两者当成一件事，就会重复 2.5 的问题，或者反过来把集群版标成生产 pin。

---

## 1. 发布后的标签

发布前先执行 `npm view @webofcat/jsonsqlite dist-tags --json`，记下当时的值。

| 标签 | 发布后 |
|------|--------|
| `latest` | **3.5.0** |
| `lts` | 与发布前相同，应为 **2.2.0** |
| `lts-2` | 与发布前相同，应为 **2.2.0** |
| `lts-3` | 与发布前相同，应为 **2.5.0** |

不新增 `lts-4`。不执行 `npm dist-tag add @webofcat/jsonsqlite@3.5.0 lts`。不删除已有标签。

---

## 2. 先改安装包里的文字，再 publish

这些文件打进核心包 tarball 或被 `npm view` 直接显示。publish 之后再改，已经发出的 3.5.0 不会变。

| 位置 | 要求 |
|------|------|
| `packages/core/package.json` 的 `version` | `3.5.0` |
| 同文件的 `description` | 含 `3.5.0`、`not LTS`、集群默认关闭、不要当作生产 pin |
| `packages/core/README.md` | 文首版本是 3.5.0，并写明禁止把本版当 LTS。不带 tag 的安装得到 `latest`（3.5.0），集群默认关闭。生产 pin 仍是 `lts`（2.2）。`lts-3` 仍是 2.5 |
| `packages/core/config.example.json` | `cluster` 与 `wasm` 出现且默认关闭。关闭时 `open` 与 3.4 相同 |
| 仓库根 `README.md`、`CHANGELOG.md` | 与上面同一套标签句子。写明 WASM 写路径不在本版承诺里 |

`description` 使用这一句：

```text
JSON-native embedded database for Node.js — 3.5.0 cluster soak (not LTS; cluster default off; do not pin as production)
```

不要出现 LTS、LTS-4、设计完工、Vision Complete。

### WASM 包

只读实验包随本版一起发布，不能整项后移。它使用接入说明里的独立包名，不发布进核心包的 bin。

- description 含 `experimental` 和 `read-only`。
- 不把该包标成 `@webofcat/jsonsqlite` 的 `lts` 或 `latest`。
- 核心包的 `latest` 仍然必须是 3.5.0。WASM 包自己的 `latest` 只属于那个包。

## 3. 发布命令

在 `packages/core` 执行。仓库根是 `"private": true`，不能在根目录 publish。

```bash
pnpm publish --access public
```

不要加 `--tag`。不要用 `--tag next` 逃避 `latest`。`prepublishOnly` 会先 build 再跑测试；测试失败就不要绕过它发版。核心包核对通过后，再发布 WASM 只读包。

```bash
# 不要这样发 3.5.0
pnpm publish --access public --tag lts
pnpm publish --access public --tag lts-4
```

---

## 4. 发出后立刻核对

```bash
npm view @webofcat/jsonsqlite version
npm view @webofcat/jsonsqlite description
npm view @webofcat/jsonsqlite dist-tags --json
```

通过标准：

- `version` 是 `3.5.0`。若仍是 3.4.x，就是 `latest` 没动。
- `description` 含 `3.5.0` 和 `not LTS`。
- `latest` 是 `3.5.0`。`lts`、`lts-2`、`lts-3` 的版本号与发布前相同。没有 `lts-4`。
- WASM 包：`npm view <wasm包名> version` 有结果，description 含 `experimental` 和 `read-only`。

核心包标签不对时只改标签，不要为了改标签再 publish 一次：

```bash
npm dist-tag add @webofcat/jsonsqlite@3.5.0 latest
npm view @webofcat/jsonsqlite version
```

核心包三条命令都符合上一节之前，不要在 GitHub Release 里写「已发布」。Release 标题含非 LTS，并写明混沌三项已通过。
