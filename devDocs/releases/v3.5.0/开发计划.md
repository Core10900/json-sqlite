# JSONSQLite v3.5.0 开发计划

> 包名：`@webofcat/jsonsqlite`（集群与 WASM 可拆包）  
> 主题：**集群浸泡**——选主、自动分片、跨机锁、可选只读 WASM  
> 前置：**3.4.0** 的复制硬化与接入层已绿  
> **LTS：否。本版禁止宣布 LTS，也禁止使用设计完工或 Vision Complete 作为发版标题**  
> 兼容：集群 API 默认关闭。关闭时不得破坏 3.4 的单机与异步复制行为  
> 路线图：[../ROADMAP.md](../ROADMAP.md) · 矩阵：[../FEATURE-MATRIX.md](../FEATURE-MATRIX.md)  
> 浸泡：`3.5.x` 只修缺陷，不新增命令，不改默认开关。通过浸泡之后才能开 **3.6** 计划的冻结验收

---

## 1. 为什么集群不能在这一版成为长期稳定版

选主、分片迁移和跨机锁只要有一条混沌断言不成立，就会静默丢写或双主。3.5 是这些能力的第一次完整实现加浸泡。3.6 才有资格冻结。没有人能在 3.5 发版当天宣布 LTS。

WASM 若随本版发布，只作为可选包，优先只读。写路径未经过与服务端相同的崩溃测试之前，标 experimental，不进入 3.6 的写入承诺。

---

## 2. 目标

1. RFC 合并前不写实现。RFC 覆盖选主、网络分区、分片迁移中的读写、跨机锁的冲突码。  
2. 三节点：能选出唯一主；杀死主后按 RFC 重新选出主；已提交数据仍在。  
3. 网络分区下不出现两个主同时接受写入。  
4. 自动分片 / rebalance：迁移过程中查询要么成功，要么返回稳定错误，不静默少文档。  
5. 数据倾斜建议只出现在 Advisor 输出里。它不自动执行 rebalance。  
6. 跨机锁冲突有稳定错误码，并写明锁的范围。  
7. 默认关闭。关闭时 3.4 的单机与复制回归绿，帮助里可以不出现 `cluster` 子命令。打开之后，只有混沌已通过的子命令进入稳定帮助。  
8. 混沌三项（杀主重选、分区无双主、rebalance 不丢文档）**全部通过**才允许发布 `3.5.0`。做不到就继续修，不把失败项写成已支持，也不发一个「实验性已支持」的 3.5.0。  
9. WASM 以可选包发布，只读，标 experimental。它是本版交付的一部分，不能整项后移。写路径未经过与服务端相同的崩溃测试之前，不进入 3.6 的写入承诺。主 bin 不包含该入口。  
10. `cluster` 与 `wasm` 在实现之后写入 `config.example.json`，默认关闭，并移出危险键。关闭时 `open` 与 3.4 相同。

### 成功标准

- RFC 链接在仓库中。  
- 混沌三项全绿，结果写进 Release。  
- `lts: false`。  
- 默认配置不启用集群。  
- FT-V35-* 全绿。

### 不做

新的查询语言、新的 SQL 方言、多语言 TCP、把 WASM 写进主 bin、在本版宣布 LTS-4。

## 4. 文档交付：同步更新 `packages/core/README.md`

本版开发完成、勾选验收之前，必须在同一次交付里更新 [`packages/core/README.md`](../../../packages/core/README.md)。把未通过的混沌项写成已支持，本版验收直接失败。本版的门禁是三项都通过，因此 README 写的是已经通过的行为，而不是计划中的策略。

写作要求：

- 与 RFC、混沌结果、Release 用词一致。
- 「如何保持关闭」写在「如何打开集群」之前。
- 文首写明 **3.5.0、非 LTS**。不得出现设计完工或 Vision Complete。`lts: false`。3.6 尚未发布。
- 不修改 `lts` / `lts-2` / `lts-3` 的指向。

本版 README 必须写清：

1. 默认关闭的配置，以及不打开时行为与 3.4 的单机、异步复制相同。
2. 已合并 RFC 的链接。步骤与断言来自 RFC。
3. 选主：三节点如何看出唯一主（状态字段名），杀死主后如何重新选出，已提交数据仍在。给出 `cluster status` 示例。
4. 网络分区：两个主不会同时接受写入。写明拒绝的错误码。
5. rebalance：迁移中查询要么成功要么返回哪个错误码。失败时调用方如何停写。Advisor 的倾斜建议不会自己触发这条命令。
6. 跨机锁：冲突错误码，以及哪些操作会碰到这把锁。
7. CLI 示例只包含已经通过混沌的子命令。
8. WASM：包名、安装命令、只读、experimental、不进入 LTS 的写入承诺。主 bin 的帮助里没有该入口。  
9. `config.example.json` 中集群与 WASM 默认关闭。`config validate` 接受这两个键的关闭态。  
10. 写明 **3.6 / LTS-4 尚未存在**。3.5.x 只修缺陷。本 README 不承诺 3.6 的发布日期。

## 6. 风险

| 风险 | 缓解 |
|------|------|
