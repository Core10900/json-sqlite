# JSONSQLite v2.4.0 功能测试计划

> 前缀：`FT-V24-*` · **非 LTS** · 默认配置回归 LTS-2

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V24-GATE-01 | 锁协议 RFC | 崩溃后锁恢复的断言可从 RFC 找到 |
| FT-V24-REG-01 | `writers: single` | FT-V22 绿；第二进程被拒绝 |

## 1. 多写者

| ID | 场景 | 期望 |
|----|------|------|
| FT-V24-CON-01 | 两进程更新同一 `_id` | 一方成功，另一方稳定错误码；胜者数据在 |
| FT-V24-CON-02 | 两进程写不同文档 | 两者都在 |
| FT-V24-CON-03 | 提交后崩溃 | 重启已提交在、未提交不在；索引一致 |
| FT-V24-CON-04 | fsync 前杀死 | 不出现半文档；行为符合 RFC |
| FT-V24-ISO-01 | SERIALIZABLE 冲突 | 一方回滚，无脏写 |
| FT-V24-ISO-02 | single 模式请求 SER | 仍被拒绝 |
| FT-V24-DLK-01 | 构造等待环 | 一方得到死锁错误并回滚 |
| FT-V24-TX-01 | savepoint 回滚 | 外层修改仍在；内层撤销 |
| FT-V24-CLI-01 | `--writers multi` | 非 TTY；doctor 能看到模式 |
| FT-V24-VER-01 | version | `2.4.0`，`lts: false` |

## 放行

1. GATE、REG、CON、DLK 全绿。  
2. 任一条崩溃注入出现静默丢写，不得发版。  
3. Release 写明多写者生产 pin 是 2.5，不是本版。
