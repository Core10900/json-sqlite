# JSONSQLite v1.5.5 开发计划

> 包名：`@webofcat/jsonsqlite`  
> 主题：**CLI 体验与命令面 LTS 化**（插在 1.5.0 与 1.6.0 之间）  
> 前置假设：`1.5.0` 已交付 rekey / vacuum / doctor --deep / lazy 等引擎与运维能力  
> 后继：`1.6.0` LTS 冻结根目录 `CLI-API.md` / `API.md`——**1.5.5 必须把 CLI 做到「可冻结」质量**

---

## 1. 背景与目标

```text
1.4  加密 / LIKE·JOIN / export·import / cursor
1.5  生产就绪（引擎 + 运维能力）
1.5.5 CLI 优化与常用命令扩展（交互 + 功能达 LTS 要求）  ← 本文
1.6  LTS：契约冻结 + 根目录权威文档
```

当前 CLI（至 1.3/规划中 1.4–1.5）存在的典型缺口：

| 问题 | 表现 |
|------|------|
| 命令面不齐 | 引擎有 CRUD/索引/事务/聚合，CLI 大量只能靠 `run` SQL 或 JSON `query` |
| 交互体验不均 | `create`/`alter` 对话尚可；`show` 翻页弱；缺统一 prompt/取消/彩色与无色模式 |
| 脚本化不彻底 | 部分命令仍绑 TTY；JSON/表格双输出不统一；exit code 未成体系 |
| help 与实现易漂移 | help 文案手工维护；子命令发现性差（无 `jsonsqlite table --help` 分级） |
| 缺少「常用运维动作」 | insert/update/delete 一行命令、索引管理、事务脚本、explain/统计等 |

**1.5.5 目标**：在不改变引擎核心语义的前提下，把 **CLI 命令面、交互、输出、错误与可脚本性** 提升到与 1.6 LTS 相同的质量条；为根目录 `CLI-API.md` 提供最终可冻结的命令清单。

### 1.5.5 成功标准（对齐 LTS 要求）

1. **常用能力 CLI 可达**：表/行 CRUD、索引、SQL、备份、vacuum、rekey、doctor、导出导入、统计——无需写 Node 脚本即可完成日常操作  
2. **交互与非交互双一流**：TTY 下引导清晰、可取消、二次确认一致；CI/管道下全部关键路径可用 flags，**禁止无提示挂起**  
3. **输出契约稳定**：默认人类可读表；`--json` 机器可读；`--quiet` 仅必要信息；exit code 文档化  
4. **命令发现性**：分级 `--help`；统一 flags（`--path` / `-p`、`--yes` / `-y`、`--json`）  
5. **无破坏性惊喜**：危险操作统一二次确认策略；`--yes` 语义全命令一致  
6. **FT-V155-* 全绿**；命令清单可作为 1.6 `CLI-API.md` 直接输入

## 4. 交互设计原则（LTS 级）

1. **可预测**：同样输入 → 同样 exit code 与输出形状（稳定字段名）  
2. **可脚本**：所有写操作提供非交互等价路径  
3. **可发现**：`--help` 任一子树可用；错误信息带「你是不是想用 xxx」  
4. **可撤销意识**：破坏性操作默认保守；`--yes` 显式跳过  
5. **可访问**：支持 `NO_COLOR`；不依赖仅 emoji 传达状态  
6. **可中断**：SIGINT 释放 DB 锁并 `close()`  

### 对话流示例（优化后 `table create`）

```text
表名: users
字段 #1 名称（回车结束）: name
类型 [string]: 
字段 #2 …: age
类型 [string]: number
—— 预览 ——
  users (name:string, age:number)
确认创建？[Y/n]: 
✓ 已创建
```

非交互：

```bash
jsonsqlite table create --name users --field name:string --field age:number -p ./data --json
```
