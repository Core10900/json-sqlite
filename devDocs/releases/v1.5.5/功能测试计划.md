# JSONSQLite v1.5.5 功能测试计划

> 用例前缀：`FT-V155-*`

## 1. 全局契约

| ID | 场景 | 期望 |
|----|------|------|
| FT-V155-G-01 | `--help` / `help` | exit 0；含主要命令 |
| FT-V155-G-02 | `table --help` / `table create --help` | 分级 help 可用 |
| FT-V155-G-03 | 未知命令 | exit 1；stderr 含建议 |
| FT-V155-G-04 | `-p` 与 `--path` 等价 | 行为一致 |
| FT-V155-G-05 | `--json` 成功 | stdout 为合法 JSON；含 `ok: true` 或约定字段 |
| FT-V155-G-06 | `--json` 失败 | stdout/stderr JSON 含 `ok: false` 与 `code` |
| FT-V155-G-07 | `NO_COLOR=1` | 无 ANSI 颜色码 |
| FT-V155-G-08 | Exit code 锁失败 | 二次 open 场景 CLI 映射为约定码（如 3） |

## 2. TTY / 非交互门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V155-TTY-01 | 非 TTY 跑对话 `table create`（无 flags） | 立即失败；提示 `--name/--field`；不挂起 |
