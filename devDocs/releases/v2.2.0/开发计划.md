## 1. 目标与 LTS 意义

在 2.0–2.1 浸泡后，把仍缺的「设计清单高频项」补齐并**冻结 2.2 契约**，成为迁离 1.6 后的推荐 pin：

1. **GeoIndex**（GeoJSON）  
2. **L3 Redis** 可选缓存（缺省不影响安装）  
3. **中文分词**插件（jieba 类或同等）  
4. **向量化批处理**（chunk 执行）  
5. 复制拓扑：**读写分离路由** + 三节点运维手册  
6. 可选 **savepoint**（默认关或显式 API）  
7. **`config.example.json`** 对齐方案 §9  
8. 冷存储 / queryLanguage 插件面完善  

### LTS-2 承诺（写入 README / API.md 文首）

- 不删除 2.2 文档中的稳定符号  
- 不缩小已承诺 SQL / 隔离语义（安全修复除外）  
- CLI 稳定子命令不静默改名  
- `formatVersion` 升级必须可迁移  
- 新功能进 **2.3+** 或 **3.0**，不进 `2.2.x` PATCH  

### 成功标准

- Geo / L3 / 分词 / 向量化均有自动化测  
- 三节点复制 demo + 手册可跟做  
- 宣布 LTS-2；说明与 **LTS-1（1.6）** 并行窗口  
- FT-V22-* 全绿
