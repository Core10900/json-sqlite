# JSONSQLite v3.6.0 功能测试计划

> 前缀：`FT-V36-*`  
> **LTS-4 放行测试**。本版不证明新功能，只证明 3.5 的契约在冻结后仍然成立。

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V36-VER-01 | `version --json` | `3.6.0`，`lts: true`，`ltsLine` 为 `3.6` |
| FT-V36-REG-01 | 默认配置 | 单写者、复制关、集群关；FT-V25 single 与 3.2 单机回归绿 |
| FT-V36-FMT-01 | 打开 3.5 库 | `formatVersion` 不升；默认开关不变 |

## 1. 迁移与冻结

| ID | 场景 | 期望 |
|----|------|------|
| FT-V36-MIG-01 | 2.5 库按迁移指南打开 | 抽样一致；写者模式 single；复制关；集群关 |
| FT-V36-OPT-01 | 显式打开 3.1 存储开关 | FT-V31 抽样绿 |
| FT-V36-REP-01 | 显式打开复制 | FT-V33 杀主用例与 FT-V34 Quorum 用例绿 |
| FT-V36-CLU-01 | 显式打开集群 | FT-V35 混沌三项绿 |
| FT-V36-CLI-01 | 帮助与 `CLI-API.md` 快照 | 相对 3.5 最后一个补丁没有新增子命令 |
| FT-V36-DOC-01 | Release | 标题含 LTS-4；写明默认不启用复制和集群 |
| FT-V36-DOC-02 | 迁移指南 | 文件存在，步骤覆盖 2.5 → 3.6 与 3.5 → 3.6 |

## 放行

1. VER、REG、MIG、REP、CLU、CLI 全绿。  
2. 默认配置打开复制或集群，不得宣布 LTS-4。  
3. 出现 3.5 没有的命令或格式版本，不得发版。
