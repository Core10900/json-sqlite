# JSONSQLite v1.4.0 功能测试计划

> 对应用例 ID 前缀：`FT-V14-*`  
> 实现前以本表为准；实现时落在 `packages/core/test/v1.4-*.test.ts`

---

## 1. 安全 / 加密

| ID | 场景 | 步骤摘要 | 期望 |
|----|------|----------|------|
| FT-V14-SEC-01 | 加密库写入可读 | `open({ encryptionKey })` → insert → close → 再 open 同钥 → query | 数据一致 |
| FT-V14-SEC-02 | 无密钥打不开密文库 | 加密写入后 `open` 不带 key | 明确错误码（非空结果） |
| FT-V14-SEC-03 | 错误密钥 | 错误 key open | 失败或无法解密业务行 |
| FT-V14-SEC-04 | 明文库兼容 | 无 key 的 1.3 风格库在 1.4 下 CRUD | 行为与 1.3 兼容 |
| FT-V14-SEC-05 | 磁盘非明文 | 读 `data.jsonl` / wal 原始内容 | 不含明文业务字段（有 key 时） |
| FT-V14-SEC-06 | 备份加密往返 | `encryptionKey` + `backupFull` + restore | 文档可恢复 |

## 2. SQL LIKE

| ID | 场景 | 期望 |
|----|------|------|
| FT-V14-LIKE-01 | `name LIKE '寒%'` | 前缀匹配 |
| FT-V14-LIKE-02 | `name LIKE '%猫'` | 后缀匹配 |
| FT-V14-LIKE-03 | `name LIKE '_b_'` | 单字符通配 |
| FT-V14-LIKE-04 | 字面 `%`（若实现转义） | 按文档；未实现则记为 skip 并文档声明 |
| FT-V14-LIKE-05 | 旧 contains 行为不回归 | `LIKE '%x%'` 仍可用 |

## 3. SQL JOIN

| ID | 场景 | 期望 |
|----|------|------|
| FT-V14-JOIN-01 | `INNER JOIN` 等值 | 仅匹配行；列可投影 |
| FT-V14-JOIN-02 | `LEFT JOIN` | 左表全保留；右无匹配为 null/缺省 |
| FT-V14-JOIN-03 | JOIN + WHERE + ORDER + LIMIT | 组合正确 |
| FT-V14-JOIN-04 | 无 ON / 非法多 JOIN | `SQL_UNSUPPORTED` 或 `SQL_PARSE` |
| FT-V14-JOIN-05 | 列名冲突 | 有稳定前缀或别名策略（与文档一致） |

## 4. 导出 / 导入 / 游标

| ID | 场景 | 期望 |
|----|------|------|
| FT-V14-IO-01 | `exportCollection` | 返回全部文档（或流）且与 query 一致 |
| FT-V14-IO-02 | `importCollection` append | 条数增加；`_id` 冲突策略明确 |
| FT-V14-IO-03 | `importCollection` replace | 表内容被替换 |
| FT-V14-IO-04 | CLI export/import 文件 | 往返后 count 一致 |
| FT-V14-CUR-01 | `queryCursor` 两页 | 无重复、无遗漏；`nextCursor` 空表示结束 |
| FT-V14-CUR-02 | 无 orderBy | 默认按 `_id` 稳定翻页 |

## 5. Admin / CLI / 版本

| ID | 场景 | 期望 |
|----|------|------|
| FT-V14-ADM-01 | 绑定非 loopback 且无 token | 拒绝启动或强制要求 token |
| FT-V14-ADM-02 | loopback 无 token | 可启动；stderr 有安全告警 |
| FT-V14-CLI-01 | `table export` / `import` | exit 0；数据正确 |
| FT-V14-VER-01 | `getVersion()` | `1.4.0` |
