> 包名：`@webofcat/jsonsqlite`  
> 主题：**2.x 硬化——隔离级别、死锁、运维闭环、复制 Quorum 打磨**

> **LTS：否**（浸泡期；为 **LTS-2 = 2.2** 铺路）

> 路线图：[../ROADMAP.md](../ROADMAP.md) · 矩阵：[../FEATURE-MATRIX.md](../FEATURE-MATRIX.md)

## 1. 目标

2.0 引入破坏性能力后，本版本把「能演示」变成「敢加压」：

1. 兑现方案 §7.2：**REPEATABLE_READ**、**SERIALIZABLE**（可配置；默认仍可为 READ_COMMITTED）  
2. **死锁检测**与明确错误码  
3. 运维：差异备份、保留策略、告警、审计日志、定时备份、AutoTune 灰度+回滚  
4. 智能压缩算法集（delta/dict/RLE + adaptive 选择）  
5. 复制：**Quorum** 可配置并与 health 联动  

### 成功标准

- 隔离级别矩阵有集成测；SERIALIZABLE 有可复现冲突用例  
- 人为构造死锁 → 一方回滚 + 稳定 code  
- differential 备份 + keepDays 可脚本化  
- 告警可订阅（EventEmitter / webhook 配置）  
- FT-V21-* 全绿；2.0 迁移库可升 2.1  

### 不做（留给 2.2 / 3.0）

GeoIndex、L3 Redis、Raft 选主、GraphQL、WASM。
