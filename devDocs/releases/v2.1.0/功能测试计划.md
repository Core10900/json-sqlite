# JSONSQLite v2.1.0 功能测试计划

> 前缀：`FT-V21-*` · **非 LTS** · 回归含 FT-V20 正确性路径 · 仍为单写者

| ID | 场景 | 期望 |
|----|------|------|
| FT-V21-BK-01 | differential 往返 | 与源抽样一致 |
| FT-V21-BK-02 | keepDays / 最大份数 | 过期份删除，未过期保留 |
| FT-V21-BK-03 | interval 关闭 | 进程内无备份定时任务 |
| FT-V21-BK-04 | 备份写入失败 | 告警发出；库仍可读写已提交数据 |
| FT-V21-MON-01 | 错误率或损坏阈值 | EventEmitter 或 webhook 收到一条 |
| FT-V21-AUD-01 | rekey / rollbackToTime / drop / migrate | `audit list` 可查到 |
| FT-V21-REC-01 | 损坏索引分段后 reopen | 索引重建且查询结果正确 |
| FT-V21-REC-02 | 数据页损坏 | open 失败，有稳定错误码 |
| FT-V21-REC-03 | 显式 repair | 文档描述的结果可断言；未显式时不静默改数据 |
| FT-V21-TUN-01 | AutoTune 应用后校验失败 | 索引集合回到应用前 |
| FT-V21-Q-01 | `$regex` | 命中与不命中符合表达式；非法表达式失败 |
| FT-V21-Q-02 | 高选择性过滤 | 页读取次数低于全表页数（计划或计数器） |
| FT-V21-Q-03 | Advisor dry-run | 有建议且不创建索引 |
| FT-V21-CLI-01 | `backup --type differential` | 非 TTY 可跑 |
| FT-V21-CLI-02 | `tune --dry-run` | 不改库 |
| FT-V21-REG-01 | FT-V20 WAL / checksum / RR / 分页 | 仍绿 |
| FT-V21-VER-01 | version | `2.1.0`，`lts: false` |

## 放行

1. 上表全绿。  
2. 不把 Quorum、多写者、列存列为条件。  
3. Release 写明下一版 2.2 将冻结本契约。
