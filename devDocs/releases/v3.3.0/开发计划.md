# JSONSQLite v3.3.0 开发计划

> 包名：核心仍 `@webofcat/jsonsqlite`；适配器与向量插件可拆包  
> 主题：**接入层与可选插件**  
> 前置：**3.2.0 LTS-4** 已宣布。稳定用户按需留在 LTS-2 / LTS-3 / LTS-4  
> **LTS：否**  
> 兼容：相对 3.2 为 MINOR。新能力优先独立包，默认不改变单机与复制契约  
> 路线图：[../ROADMAP.md](../ROADMAP.md)

---

## 1. 目标

大纲接口层里还没进生产契约的部分放在这里，避免它们挡住任何一条 LTS：

1. GraphQL 适配：查询与变更映射到现有 JSON API。可子包。  
2. 连接池：同进程复用，close 后无泄漏句柄。  
3. 多数据库注册表：至少两个 `storagePath`，锁与数据隔离。  
4. Express 与 Nest 示例（或独立包）能完成一次写入再读回。  
5. Advisor 可选 `advisorProvider`。未配置时仍是规则引擎，安装包不依赖外部 LLM。  
6. Vector 插件的可用实现：相似度检索 API，文档写明这不是通用向量库。  
7. 包拆分若发生，先改《npm 包与后端接入说明》的 publish 边界。

### 不做

Raft、自动分片、WASM、自动选主。

### 成功标准

- 不加载这些适配器时，LTS-4 的单机与复制回归绿。  
- FT-V33-* 全绿。  
- Release 标明非 LTS。

## 2. 需求

| ID | 需求 |
|----|------|
| V33-GQL-1 | GraphQL 覆盖常用 CRUD / query |
| V33-POOL-1 | 连接池借还与关闭 |
| V33-MDB-1 | 多库隔离 |
| V33-FW-1 | Express 示例 |
| V33-FW-2 | Nest 示例或包 |
| V33-AI-1 | 可选 provider；默认无 LLM |
| V33-VEC-1 | 向量检索可用实现与小样本说明 |
| V33-CLI-1 | 见下表；不删除已冻结 LTS 命令 |

### CLI（3.3）

| ID | 命令 | 说明 |
|----|------|------|
| V33-CLI-A | `db list\|register\|use\|unregister` | 多库 |
| V33-CLI-B | `serve graphql` 或子包 bin | 文档写清入口在哪 |
| V33-CLI-C | `plugin` 可安装 vector 示例 | 不把 WASM 塞进同一个 bin |

## 3. 验收

- [ ] GraphQL 与库 API 结果一致  
- [ ] 池关闭无泄漏  
- [ ] 双库数据不串  
- [ ] 无 provider 时 Advisor 仍返回规则建议  
- [ ] 向量示例可运行并说明边界  
- [ ] LTS-4 回归绿
