# JSONSQLite v3.3.0 开发计划

> 包名：核心仍 `@webofcat/jsonsqlite`；适配器与向量插件可拆包  
> 主题：**接入层与可选插件**  
> 前置：**3.2.0 LTS-4** 已宣布。稳定用户按需留在 LTS-2 / LTS-3 / LTS-4  
> **LTS：否**  
> 兼容：相对 3.2 为 MINOR。新能力优先独立包，默认不改变单机与复制契约  
> 路线图：[../ROADMAP.md](../ROADMAP.md)

---

## 1. 目标

大纲接口层里还没进生产契约的部分放在这里，避免它们挡住任何一条 LTS：

1. GraphQL 适配：查询与变更映射到现有 JSON API。可子包。  
2. 连接池：同进程复用，close 后无泄漏句柄。  
3. 多数据库注册表：至少两个 `storagePath`，锁与数据隔离。  
4. Express 与 Nest 示例（或独立包）能完成一次写入再读回。  
5. Advisor 可选 `advisorProvider`。未配置时仍是规则引擎，安装包不依赖外部 LLM。  
6. Vector 插件的可用实现：相似度检索 API，文档写明这不是通用向量库。  
7. 包拆分若发生，先改《npm 包与后端接入说明》的 publish 边界。

### 不做

Raft、自动分片、WASM、自动选主。

### 成功标准

- 不加载这些适配器时，LTS-4 的单机与复制回归绿。  
- FT-V33-* 全绿。  
- Release 标明非 LTS。

## 3. 文档交付：同步更新 `packages/core/README.md`

本版开发完成、勾选验收之前，必须在同一次交付里更新 [`packages/core/README.md`](../../../packages/core/README.md)。接入层和可选插件容易被写成「核心已经依赖 LLM / 向量库 / GraphQL」。只改版本号不算完成；未发布的包名也不能先写进安装命令。

写作要求：

- 与已发布的包边界一致。拆包时先改《npm 包与后端接入说明》的 publish 边界，README 的安装命令、包名、入口与之一致，不超前。
- 不加载这些适配器时，单机与复制契约不变。README 仍把默认路径放在适配器之前。
- 每个新能力都有可复制示例：安装（若在子包）、最小调用、关闭或卸载、失败或未配置时的结果。
- 文首写明 **3.3.0、非 LTS**。稳定用户按需留在 LTS-2 / LTS-3 / LTS-4。

本版 README 必须写清：

1. 包边界：核心仍是 `@webofcat/jsonsqlite`。GraphQL、Express、Nest、向量插件若独立成包，分别写包名、`npm install` 命令、程序入口在主包还是子包 bin。未拆包则写明入口仍在主包，并给出命令。
2. GraphQL：查询与变更如何映射到现有 JSON API。一次查询示例、一次变更示例，以及结果与库 API 一致时读者如何对照。写明不支持的操作（若有范围裁剪），不要写「完整 GraphQL 数据库」。
3. 连接池：同进程内借出、归还、`close`。示例必须包含关闭。写明 close 之后没有泄漏句柄，调用方不应再使用已归还或已关闭的连接，以及再次使用时的结果。
4. 多数据库：至少两个 `storagePath` 的注册示例。`db list`、`register`、`use`、`unregister` 各给命令。说明锁与数据隔离：读 A 库看不到 B 库的写入，关掉 A 不影响 B。
5. Express 与 Nest：示例代码放在仓库的路径、如何启动、如何完成一次写入再读回。示例若在独立包，安装与启动命令写全。两个框架都要出现；Nest 若以包交付，写包名而不是「或另见仓库」。
6. Advisor：未配置 `advisorProvider` 时仍是规则引擎，安装本包不依赖外部 LLM。写明不配置时返回的是规则建议、建议里有什么。配置 provider 是可选路径：如何注入、失败时是否拖垮查询（按实现写，未隔离就不要写隔离）。
7. Vector：可用的相似度检索 API，包括如何建索引、一条查询、返回里距离或分数的含义。文档写明这不是通用向量库，并写小样本边界：适合的规模、不保证的过滤或实时性、与 2.3 stub 的差别（本版是可运行实现，不是占位）。
8. CLI：不删除已冻结的 LTS 命令。`serve graphql` 或子包 bin 的入口写清「命令在哪、进程是谁」。`plugin` 安装 vector 示例的命令写出来。WASM 不塞进同一个 bin，安装说明里不要出现 WASM。
9. 明确不在本版：Raft、自动分片、WASM、自动选主。
