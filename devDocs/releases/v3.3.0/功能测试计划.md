# JSONSQLite v3.3.0 功能测试计划

> 前缀：`FT-V33-*` · **非 LTS** · 必须回归 LTS-4 的单机与复制关闭路径

| ID | 场景 | 期望 |
|----|------|------|
| FT-V33-GQL-01 | GraphQL query / mutation | 与库 API 抽样一致 |
| FT-V33-GQL-02 | 未授权 | 拒绝，有文档化的方式 |
| FT-V33-POOL-01 | 并发借还后 close | 无悬挂句柄；超额行为有文档 |
| FT-V33-MDB-01 | 两个 storagePath | 写入互不可见 |
| FT-V33-FW-01 | Express 示例 | 健康检查 + 一次写读 |
| FT-V33-FW-02 | Nest 示例 | 同上，若本版交付该包 |
| FT-V33-AI-01 | 无 provider | 规则建议仍在 |
| FT-V33-AI-02 | 自定义 provider | 被调用；核心测试不访问外网 |
| FT-V33-VEC-01 | 相似度检索 | 小样本上的顺序可断言；文档否认通用向量库定位 |
| FT-V33-CLI-01 | `db list\|register\|use` | 非 TTY |
| FT-V33-REG-01 | 不启用适配器 | LTS-4 单机回归绿 |
| FT-V33-VER-01 | version | `3.3.0`，`lts: false` |

## 放行

1. GQL、POOL、MDB、AI-01、REG 全绿。  
2. 不得把本版标成任何 LTS。
