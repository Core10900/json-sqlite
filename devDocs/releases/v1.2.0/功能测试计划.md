# JSONSQLite v1.2.0 功能测试计划

| ID | 场景 | 期望 |
|----|------|------|
| FT-V12-TBL-01 | `listTables` / `createTable` | 建表后列表可见；含 fields |
| FT-V12-TBL-02 | `dropTable` | catalog 与磁盘目录清除；再查报错 |
| FT-V12-TBL-03 | `alterTable` rename / add / drop field | 元数据正确；rename 后数据可查 |
| FT-V12-SHOW-01 | `query` + `count` 分页 | offset/limit 与总数正确 |
| FT-V12-SQL-01 | `SELECT` WHERE / ORDER / LIMIT | 结果与 JsonQuery 一致 |
| FT-V12-SQL-02 | `INSERT` / `UPDATE` / `DELETE` | 行变更正确 |
| FT-V12-SQL-03 | `CREATE` / `DROP` / `ALTER` / `SHOW` / `DESCRIBE` | DDL 生效 |
| FT-V12-SQL-04 | 非法 SQL | 抛出明确错误码 |
| FT-V12-CLI-01 | `run` 非交互 | stdout 含结果；exit 0 |
| FT-V12-CLI-02 | `tables` | 输出表名 |
| FT-V12-VER-01 | `getVersion` | `1.2.0` |
