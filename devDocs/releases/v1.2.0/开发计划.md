# JSONSQLite v1.2.0 开发计划

> 包名：`@webofcat/jsonsqlite`  
> 目标：CLI 友好的表管理（查看 / 对话式新建 / 二次确认删除与修改 / 分页看数据），以及 **`jsonsqlite run` + SQL**；库 API 同步支持 SQL。

---

## 1. 需求摘要

| 需求 | 目标行为 |
|------|----------|
| 查看所有表 | CLI `tables` / `table list`；库 `listTables()`（集合即表） |
| 新建表 | CLI 对话式引导（表名 → 字段 → 确认）；库 `createTable()` |
| 删除表 | CLI 二次确认（yes + 再输表名）；库 `dropTable()` 清理磁盘 |
| 修改表 | CLI 对话式改名/增减字段定义，二次确认；库 `alterTable()` |
| 查看表数据 | CLI `table show` 友好表格 + 分页；库 `query` / `count` |
| SQL | CLI `run '<sql>'`；库 `run(sql)`（编译到现有 JSON Query / CRUD） |

说明：JSONSQLite 仍是文档库；「表」= collection；字段为 **软 Schema**（元数据提示，不强制校验写入，便于对话建表）。

---

## 2. SQL 子集（v1.2.0）

| 语句 | 支持 |
|------|------|
| `SELECT … FROM t [WHERE] [ORDER BY] [LIMIT] [OFFSET]` | ✅ |
| `INSERT INTO t [(cols)] VALUES (…)` | ✅ |
| `UPDATE t SET … [WHERE]` | ✅ |
| `DELETE FROM t [WHERE]` | ✅ |
| `CREATE TABLE t [(col type, …)]` | ✅ |
| `DROP TABLE t` | ✅ |
| `ALTER TABLE t RENAME TO` / `ADD COLUMN` / `DROP COLUMN` | ✅ |
| `SHOW TABLES` / `DESCRIBE t` | ✅ |
| JOIN / 子查询 / 事务 SQL | ❌（后续版本） |

## 4. CLI 草图

```bash
jsonsqlite tables --path ./data
jsonsqlite table create --path ./data          # 对话
jsonsqlite table drop users --path ./data      # 二次确认
jsonsqlite table alter users --path ./data     # 对话 + 二次确认
jsonsqlite table show users --path ./data --page 1 --size 20
jsonsqlite run "SELECT * FROM users WHERE age > 18 LIMIT 10" --path ./data
```
