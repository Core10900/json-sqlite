# JSONSQLite v1.3.0 开发计划（硬化）

> 目标：修复 1.2.0 稳定性评估中的 Critical / Important 缺口，使 1.3 可作为「可长期维护」的候选基线（仍非多写者 / 硬 Schema 的 2.0）。

## 范围

| 优先级 | 项 | 状态 |
|--------|----|------|
| Critical | 原子 catalog + syncMode fsync | ✅ |
| Critical | DDL journal（drop/rename 崩溃恢复） | ✅ |
| Critical | 隔离级别诚实化（仅 READ_COMMITTED） | ✅ |
| Critical | formatVersion 迁移钩子 | ✅（框架；仍为 v1） |
| Important | schemaMode off/warn/strict | ✅ |
| Important | CLI TTY / `--yes` / `--name --field` | ✅ |
| Important | SQL IN / BETWEEN / IS NULL；count 优化 | ✅ |
| Important | queryTimeout 生效 | ✅ |

## 非目标（留给后续）

- 主存储加密、多写者、JOIN、完整 SQL LIKE、硬 Schema 默认开启
