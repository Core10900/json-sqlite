# JSONSQLite v1.8.0 功能测试计划

> 用例前缀：`FT-V18-*`  
> 重点：索引落盘、L2、压缩、热冷旗标、bench 阈值、CI  
> 回归：含加密路径与 1.6/1.7 关键能力

---

## 1. 索引持久化

| ID | 场景 | 期望 |
|----|------|------|
| FT-V18-IDX-01 | 建索引 → close → open | 无需全表扫描即可服务等值/范围（可测耗时或标志位） |
| FT-V18-IDX-02 | 损坏索引文件 | doctor 报告；可 rebuild；数据不丢 |
| FT-V18-IDX-03 | 崩溃注入后索引与数据一致 | 查询结果正确 |

## 2. 缓存 / 压缩 / 分层

| ID | 场景 | 期望 |
|----|------|------|
| FT-V18-CACHE-01 | L2 关闭 | 行为同 1.7 |
| FT-V18-CACHE-02 | L2 开启 | 重复查询命中上升；写后失效 |
| FT-V18-STOR-01 | 压缩开关 | 读写 round-trip；加密库仍可开 |
| FT-V18-STOR-02 | 热冷旗标关 | 无延迟加载副作用 |
| FT-V18-STOR-03 | 热冷旗标开（小样本） | 冷文档可读；metrics 有 tier 信息 |

## 3. 性能 / CI

| ID | 场景 | 期望 |
|----|------|------|
| FT-V18-PERF-01 | bench 冒烟 | 退出 0；产出 JSON 报告 |
| FT-V18-PERF-02 | 阈值 | 相对 baseline 不超约定倍数（环境差异允许标记 skip） |

| FT-V18-CLI-01 | `index rebuild` | 非 TTY 成功或可文档化的失败码 |
| FT-V18-CLI-02 | `doctor --json` | 含索引落盘/压缩相关检查字段（若启用） |
| FT-V18-CLI-03 | CLI-API 1.8 增补 | help ⊆ 文档 |
