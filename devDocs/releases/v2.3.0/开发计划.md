# JSONSQLite v2.3.0 开发计划

> 包名：核心仍 `@webofcat/jsonsqlite`；适配器可拆子包  
> 主题：**应用接入层补齐（大纲「接口层」剩余项）**  
> 前置：**2.2.0 LTS-2** 已宣布  
> **LTS：否**（功能列车；稳定用户继续 pin 2.2.x）  
> 兼容：相对 2.2 MINOR；新能力优先独立包以免撑大 core  
> 路线图：[../ROADMAP.md](../ROADMAP.md) · 矩阵：[../FEATURE-MATRIX.md](../FEATURE-MATRIX.md)

---

## 1. 目标

大纲应用接口层在 Library/CLI/HTTP/WS 之外仍列：**GraphQL、连接池、多数据库**。本版专门补齐，并提供官方框架示例包。

1. **GraphQL 适配器**（查询/变更映射到 JsonQuery / run）  
2. **连接池**：同进程多逻辑连接复用单一引擎或受控多实例  
3. **多数据库管理器**：命名 `storagePath` 注册表、生命周期、健康汇总  
4. **Express / Nest 官方示例或 `@webofcat/jsonsqlite-nest` 等适配包**  
5. **可选 AI Advisor hook**（接口稳定；默认无外部 LLM 依赖）  

### 成功标准

- GraphQL schema 覆盖常用 CRUD/query；有集成测  
- 连接池在并发下无泄漏句柄；close 干净  
- 多库管理器可同时 open ≥2 库并隔离锁  
- 至少一个框架示例可 `pnpm` 跑通  
- FT-V23-* 绿；**不破坏 2.2 LTS 契约**  

### 不做

Raft、自动分片、WASM（→ 3.0）。

## 2. 需求摘要

| ID | 需求 |
|----|------|
| V23-GQL-1 | GraphQL 适配（可子包） |
| V23-POOL-1 | ConnectionPool API |
| V23-MDB-1 | MultiDatabaseRegistry |
| V23-FW-1 | Express 示例 |
| V23-FW-2 | Nest 模块示例/包 |
| V23-AI-1 | `advisorProvider` 可选 hook |
| V23-DOC-1 | npm 接入说明更新；标明非 LTS |
| V23-PKG-1 | 若拆包：publish 边界与 peer 依赖 |
| V23-CLI-1 | CLI-API 适配（2.3） | 见下表；不破坏 2.2 稳定命令集 |

### CLI-API 适配（2.3）

| ID | 命令 / 改动 | 说明 |
|----|-------------|------|
| V23-CLI-A | `db list\|register\|use\|unregister` | 多数据库 |
| V23-CLI-B | `serve graphql`（或文档指向子包 bin） | GraphQL 入口 |
| V23-CLI-C | `-p` vs `db use` 优先级 | 写入 CLI-API |
| V23-CLI-D | `pool status`（可选） | 连接池可观测 |
