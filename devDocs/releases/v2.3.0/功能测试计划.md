# JSONSQLite v2.3.0 功能测试计划

| ID | 场景 | 期望 |
|----|------|------|
| FT-V23-REG-01 | 默认配置跑 FT-V22 | 绿；不启用列存与插件 |
| FT-V23-COL-01 | 列存投影 | 与文档模式结果一致 |
| FT-V23-COL-02 | 列存重建期间崩溃 | 已提交以 WAL 为准可恢复 |
| FT-V23-TIER-01 | 冷层文档 | 读取正确；迁移不阻塞一次提交 |
| FT-V23-CMP-01 | 各压缩算法往返 | 字节级还原；加密开/关都测 |
| FT-V23-IDX-01 | compact 后查询 | 结果不变；reopen 命中合并段 |
| FT-V23-CACHE-01 | 大值压缩 | 命中返回原文档 |
| FT-V23-PLG-01 | 插件抛错 | 引擎继续服务已有集合 |
| FT-V23-PLG-02 | vector / S3 stub | 钩子被调用；文档标明非可用实现 |
| FT-V23-EXE-01 | chunk 与非 chunk | 结果等价 |
| FT-V23-GEO-01 | Geo 点/范围 | 结果正确；未建索引时行为有文档 |
| FT-V23-TOK-01 | 无分词依赖 | open 成功 |
| FT-V23-TOK-02 | 有分词插件 | 中文查询命中文档中的样例 |
| FT-V23-CLI-01 | `index compact` | 非 TTY |
| FT-V23-CLI-02 | 2.2 稳定命令 | 帮助与语义未删 |
| FT-V23-VER-01 | version | `2.3.0`，`lts: false` |
