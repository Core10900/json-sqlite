# JSONSQLite v3.1.0 功能测试计划

> 前缀：`FT-V31-*`  
> **非 LTS**。新存储默认关闭。

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V31-REG-01 | 无新配置打开 3.0 库 | FT-V30 回归绿 |
| FT-V31-VER-01 | version | `3.1.0`，`lts: false` |

## 1. 索引与存储

| ID | 场景 | 期望 |
|----|------|------|
| FT-V31-BT-01 | 范围查询 | `_id` 集合与对照实现一致 |
| FT-V31-BT-02 | 访问次数 | 不随键数量线性增长的断言成立 |
| FT-V31-BT-03 | `index compact` 后 reopen | 范围结果不变 |
| FT-V31-GEO-01 | 有 Geo 索引的 `$geoWithin` | 不读取包围盒外的文档体 |
| FT-V31-GEO-02 | 无 Geo 索引 | 结果正确，`explain` 标明扫描 |
| FT-V31-TOK-01 | 不传分词模块 | `open` 成功 |
| FT-V31-TOK-02 | 模块抛错 | open 成功；分词查询稳定失败；点查成功 |
| FT-V31-COL-01 | 投影 | 读取的列文件数等于投影字段数加行键 |
| FT-V31-COL-02 | 列文件 checksum 不符 | 退回文档页，查询成功 |
| FT-V31-HYB-01 | hybrid 与文档模式 | 同一投影的文档一致 |
| FT-V31-ADP-01 | `storage advise` | 不修改表的存储模式 |
| FT-V31-ADP-02 | 有过滤查询后再 advise | 输出能看出基数或嵌套深度，以及被过滤字段的计数 |
| FT-V31-ADP-03 | 超过压缩阈值的大文档 | 建议可以是 `compressed`；存储模式未被改写 |
| FT-V31-CMP-01 | 采样后的块 | 块头算法名可解压；含 front-coding |
| FT-V31-CMP-02 | 压缩后再加密 | round-trip 成功 |
| FT-V31-TIER-01 | 冷目录不可读 | 热文档按 `_id` 可读 |
| FT-V31-CACHE-01 | 预取失败 | 查询仍按需读页并成功 |
| FT-V31-STOP-01 | 默认停用词 | 与 2.5 倒排对同一句子的分词一致 |
| FT-V31-STOP-02 | 自定义停用词后重建 | 被列入的词不再命中；空表保留所有词 |

## 放行

1. REG、BT、COL、CMP、TIER-01 全绿。  
2. 默认配置写入新的列文件或冷目录，则不得发版。
