# JSONSQLite v3.1.0 功能测试计划

> 前缀：`FT-V31-*` · **非 LTS** · 回归 3.0 单机与「不自动选主」

| ID | 场景 | 期望 |
|----|------|------|
| FT-V31-QUO-01 | 确认数不足 | 写入失败，有稳定错误码；status 不把该写标成已复制 |
| FT-V31-ROUTE-01 | 读从库 | 命中从角色；写不到从库 |
| FT-V31-ROUTE-02 | 滞后超过阈值 | 行为与文档的失败或回主策略一致 |
| FT-V31-REP-01 | 杀死主 | 仍不自动选主 |
| FT-V31-S3-01 | 冷对象读写 | 读回一致 |
| FT-V31-S3-02 | 冷存储不可用 | 热集合点查成功 |
| FT-V31-AUD-01 | promote | 审计可查 |
| FT-V31-REG-01 | 复制关闭 | 单机回归绿 |
| FT-V31-CLI-01 | `replica status` | 含 quorum 与角色 |
| FT-V31-VER-01 | version | `3.1.0`，`lts: false` |

## 放行

1. QUO、ROUTE、REP、S3 全绿。  
2. Release 写明复制生产 pin 将是 3.2，不是本版。
