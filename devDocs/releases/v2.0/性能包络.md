# v2.0.0 性能包络（非 LTS）

方案 §12.3 的六个场景。数字来自本机 `apps/bench`（`syncMode: none`，`N=2000`，2026-10-28），只作实测包络，不是验收阈值。CI 继续用相对回归；绝对毫秒不是验收条。

| 场景 | 字段 | 实测 |
|------|------|------|
| 点查 | `pointQueryAvgMs` | 0.0069 ms |
| 范围 | `rangeQueryMs` | 17.06 ms |
| 全文 | `fulltextMs` | 0.49 ms |
| 批量插入 | `insertMs` | 2650.80 ms（754 行/秒） |
| 并发读 | `concurrentReadMs` | 0.11 ms |
| 并发写 | `concurrentWriteMs` | 26.05 ms |

同一次运行：`joinMs` 6.05，`reopenMs` 4.60，`rebuildMs` 71.10，`indexServedFromSegment` true。

范围查询会按命中行所在页把文档体读回缓存。对照 `apps/bench/baseline.json`（1.5.0，全量驻留）时，`rangeQueryMs` 超过 50× 上限（0.31 ms × 50）。这是分页之后的实测，不是 CI 门槛。小 `N` 与基线 `N` 不一致时，阈值比较会跳过。

复现：

```bash
BENCH_SKIP_THRESHOLD=1 BENCH_N=2000 node apps/bench/index.mjs
```

本版 **非 LTS**，默认仍是单写者。并发写是同一进程内串行落盘，不是多进程多写者。
