# JSONSQLite v2.0.0 功能测试计划

> 用例前缀：`FT-V20-*`  
> 重点：迁移、备份链、WAL 失败关闭、RR 快照、分页上限、Admin TLS  
> **非 LTS**。默认仍是单写者。本版不测多写者、复制、列存、插件。

---

## 0. 门禁

| ID | 场景 | 期望 |
|----|------|------|
| FT-V20-GATE-01 | 恢复与分页 RFC 已合并 | 坏行判定、页预算、快照交错写清 |
| FT-V20-GATE-02 | 迁移工具存在 | 1.8 样例库可迁 |

## 1. 迁移

| ID | 场景 | 期望 |
|----|------|------|
| FT-V20-MIG-01 | 明文库迁移 | 文档数与抽样一致 |
| FT-V20-MIG-02 | 加密库迁移 | 错误密钥失败；目标目录不出现 |
| FT-V20-MIG-03 | 损坏源 | 非 0；不写半成品 |
| FT-V20-MIG-04 | 重跑 | 行为与文档一致（拒绝或覆盖） |

## 2. 备份与 WAL

| ID | 场景 | 期望 |
|----|------|------|
| FT-V20-BK-01 | full → incremental → restore | 恢复后与源抽样一致 |
| FT-V20-BK-02 | 篡改 manifest checksum | 拒绝恢复；目标库字节不变 |
| FT-V20-BK-03 | 只恢复一个集合 | 其它集合保持恢复前内容 |
| FT-V20-BK-04 | 增量缺全量基线 | 失败且不部分套用 |
| FT-V20-WAL-01 | 截断最后一行 | 已提交前缀在；未完成行不在 |
| FT-V20-WAL-02 | 中间行 checksum 错误 | `open` 抛稳定错误码；不跳过该行之后的已提交记录 |
| FT-V20-WAL-03 | kill -9 于提交后 | 重启后已提交在、未提交不在 |

## 3. 隔离与分页

| ID | 场景 | 期望 |
|----|------|------|
| FT-V20-ISO-01 | RR 快照期间另一提交已完成 | 快照重复读结果不变 |
| FT-V20-ISO-02 | RC | 读到最新已提交 |
| FT-V20-ISO-03 | 配置 SER 或 READ_UNCOMMITTED | 打开或 begin 失败，有稳定错误码 |
| FT-V20-PAGE-01 | 文档数大于页预算 | 堆驻留文档数 ≤ 预算断言 |
| FT-V20-PAGE-02 | 点查未驻留文档 | 结果正确，且不是先把整表读入 |
| FT-V20-IDX-01 | 损坏索引分段 | 查询不使用该分段；doctor 报损坏 |

## 4. 安全与包络

| ID | 场景 | 期望 |
|----|------|------|
| FT-V20-TLS-01 | 非 loopback 且无 TLS | 拒绝监听 |
| FT-V20-TLS-02 | loopback 无 token | 可启动并有警告 |
| FT-V20-PERF-01 | §12.3 六场景 | 报告含点查、范围、全文、批量插入、并发读、并发写；写入 Release 附件或 `apps/bench` 输出 |

## 5. 文档 / 回归
