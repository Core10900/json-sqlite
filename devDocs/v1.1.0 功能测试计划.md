## 1. 用例列表

| ID | 优先级 | 场景 | 期望 |
|----|--------|------|------|
| FT-V11-VER-01 | P0 | `getVersion()` | 返回 `1.1.0` |
| FT-V11-VER-02 | P0 | CLI `--version` / `-V` / `version` | stdout 含版本号，exit 0 |
| FT-V11-CRT-01 | P0 | `create({ storagePath })` 新路径 | 生成 catalog，`created: true` |
| FT-V11-CRT-02 | P0 | 对已存在库再次 `create` | 抛 `DB_EXISTS` |
| FT-V11-CRT-03 | P1 | `create(..., { force: true })` | 可重建；之后 `open` 可用 |
| FT-V11-INI-01 | P0 | `init` 空路径 | 创建库，`created: true` |
| FT-V11-INI-02 | P0 | `init` 已有库（含数据） | `created: false`，原数据仍在 |
| FT-V11-CLI-01 | P0 | `jsonsqlite create ./tmp-db` | 目录与 meta 存在 |
| FT-V11-CLI-02 | P0 | `jsonsqlite init ./tmp-db` | exit 0 |
| FT-V11-BIN-01 | P0 | package.json `bin.jsonsqlite` | 指向 `dist/cli.js` |
| FT-V11-REG-01 | P0 | 原有 CRUD/WAL 等回归 | 全部绿 |

## 2. 手工验收（发布前）

```bash
pnpm --filter @webofcat/jsonsqlite build
npm pack
# 或发布后：
npm i -g @webofcat/jsonsqlite@1.1.0
jsonsqlite --version
jsonsqlite create ./demo-db
jsonsqlite init ./demo-db
jsonsqlite doctor --path ./demo-db
```

---

## 3. 发布门禁

- Blocker：`--version` 不可用 / create 损坏已有数据（非 force）
- Critical：init 非幂等、丢失数据
- 全部 P0 自动化用例必须绿
