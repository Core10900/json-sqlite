# JSONSQLite v1.0 功能测试计划

> 配套：《v1.0 开发计划》  
> 原则：每个 Must 能力有对应用例；P1 起崩溃恢复为红线；发布前全量回归。

---

## 1. 测试策略

| 层级 | 工具 | 占比（目标） | 说明 |
|------|------|--------------|------|
| 单元测试 | Vitest | ~50% | 解析器、过滤、WAL 条目、锁、压缩等 |
| 集成测试 | Vitest（临时目录） | ~35% | open→写→关→再开；事务；索引一致性 |
| 包装烟 | pack + 空项目 | ~5% | ESM/CJS 安装 |
| 性能基准 | apps/bench | ~5% | 不默认 fail CI，设回归阈值可选 |
| 手工/演示 | 脚本 | ~5% | Admin / PITR 演示清单 |

环境：Node.js ≥ 20；测试数据目录使用 `os.tmpdir()`，用例结束清理。

---

## 2. 用例编号规则

`FT-{阶段}-{模块}-{序号}`  
例如：`FT-P1-WAL-01`、`FT-P2-IDX-03`。

优先级：P0（阻塞发布）> P1（必须）> P2（重要）> P3（增强）。

## 3. P0 — 工程与生命周期

| ID | 优先级 | 用例 | 步骤摘要 | 期望 |
|----|--------|------|----------|------|
| FT-P0-LIFE-01 | P0 | open 创建数据目录 | `open({storagePath})` | 目录与 meta 存在；`isReady=true` |

## 9. 执行节奏

| 阶段出口 | 必须绿的用例集 |
|----------|----------------|
| P0 Done | FT-P0-* |

命令约定：

```bash
pnpm test                  # 单元+集成
pnpm --filter @jsonsqlite/core test
pnpm --filter @jsonsqlite/core pack:smoke   # 包装烟
```

## 10. 缺陷分级

| 级别 | 定义 | 发布门禁 |
|------|------|----------|
| Blocker | 丢已提交数据、锁失效导致损坏、pack 不可装 | 禁止发版 |
| Critical | 事务/查询结果错误 | 禁止 `1.0.0` |
| Major | 备份/监控/HTTP 核心失败 | 禁止 `1.0.0` |
| Minor | Admin UI、文案、非默认路径 | 可带已知问题发版 |
